# V3 Personal Memory 日常使用集成

2026-11-24。本轮只更新既有 Skill，不改 Worker、数据库结构、KV、Cron 或导入历史。

两端新增按语义触发的路由：历史个人问题先按需 Recall；项目续接读 Activity；已授权的长期个人结论先去重再写 Memory；实际项目里程碑写 Activity。普通问答、重复偏好、未定想法和未经明确授权的敏感内容不自动保存。原文、总结与推断须区分。

Codex 本机及仓库双端安装源均已合并，旧正文保持原样，格式检查通过。ChatGPT 在原技能内合并保存并重新打开确认；原正文、图标和产品范围保留，隐式调用仍开启。个人定制分别保留，两端无需完全相同，也不会自动互相安装。

实际工具观察：历史协作偏好已通过 Recall 找回；相同偏好去重后未再次 capture；真实 Skill 升级里程碑通过 append_activity 写回，返回 vault_synced=true。用户没有新偏好，故未进行新的个人 Memory 写入与跨 Agent 回读。

**客户端无提示自动选 Skill 尚未独立验证。** 本轮不能将工具显式可用、Skill 已保存，等同于 ChatGPT/Codex 新会话的自动触发通过；独立无关问答负例也未验证。实际工具轨迹与安装差异留在本机工作记录。

日常直接说“我上次怎么决定的”“接着那个项目做”“以后我更喜欢……”即可。下一次真实使用观察工具轨迹；仅在出现实际漏触发时针对该例调整，不再扩大基础设施测试。
